## What's in this repo

This repo is a running log of my security work: tools I've built, writeups from
CTFs and labs, infrastructure security experiments, research, and a dated
journal of ongoing progress.

- **[`tools/`](tools/)** — Scripts and tools I've built. Each tool gets its own
  subfolder.
- **[`ctf-writeups/`](ctf-writeups/)** — CTF, HackTheBox, and lab writeups, one
  subfolder per challenge.
- **[`infra-security/`](infra-security/)** — Infrastructure-as-code security
  work: Terraform hardening, Sigma detection rules, CI/CD security gates.
- **[`research/`](research/)** — Vulnerability analysis, CVE breakdowns, and
  deeper technical dives.
- **[`journal/`](journal/)** — Dated markdown log of ongoing work
  (`YYYY-MM-DD-title.md`).
- **[`templates/`](templates/)** — Currently holds
  [`PERIMETER_REPORT.md`](templates/PERIMETER_REPORT.md), a real writeup of
  perimeter.report and how it was built agentically.
